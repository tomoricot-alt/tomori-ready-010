# TOMORI READY 開発報告（APP 010）

## 概要

小学3・4年生向けの「学校の持ち物チェックリスト」。React Native + Expo (SDK 57) + TypeScript、Web は React Native Web で `https://tomoricot-alt.github.io/tomori-ready-010/` に GitHub Pages で公開する。サーバー・会員登録・有料API・広告・課金・通知なし。

## 要件と実装の対応

| 要件 | 実装 |
| --- | --- |
| 持ち物チェックリスト / チェックで完了扱い | `ReadyScreen` + `CheckRow`（タップで切り替え） |
| 曜日別テンプレート / 曜日ごとの持ち物設定 | `Templates.days`（曜日→持ち物ID）、`SettingsScreen` の「あり／なし」 |
| 明日の持ち物 / 今日・明日の切り替え | `targetDateKey` と上部の切り替えボタン |
| 準備数・達成率 | `getProgress`（四捨五入、持ち物0個は0%でお祝いなし） |
| 追加・編集・削除 | `addItem` / `updateItem` / `deleteItem`（削除は確認つき・全曜日から削除） |
| お祝い | `Celebration`（Modal + 紙ふぶき） |
| 端末内保存 | `AsyncStorage`（Webでは localStorage） |
| 前日のチェックを引き継がない | チェックは日付キー別。他日付に影響しない（テスト済み） |
| テンプレートと日付別チェックの分離 | 保存キーを `templates:v1` / `checks:v1` に分離 |

## 設計上の判断

- **持ち物は1つの一覧＋曜日ごとの参照**にした。名前や絵文字を直すと全曜日に反映され、曜日ごとに「あり／なし」を切り替えられる。
- **初期の「きょう／あした」**は、お昼まで＝きょう、お昼以降＝あした（前の晩に使う想定、朝に開いても迷わない）。
- **開きっぱなしでも日付が変わる**ように、15秒ごと・タブ復帰時に現在時刻を更新する。深夜0時をまたいでも、チェックは日付ごとなので前日分が混ざらない。
- **保存データは検証して読み込む**。壊れたJSON・存在しない持ち物ID・不正な日付キーは取り除き、読めなければ初期状態にする。読み込み完了前は保存しない（初期値で上書きしない）。
- 古いチェック記録は60日で自動削除。
- 初期サンプルは月〜金に入れ、土日は空（持ち物なしの案内を表示）。
- 個人情報の入力欄はない。名前は20文字まで、持ち物は60個まで。
- 削除の確認は `Alert` ではなく画面内の確認（Webでも同じ動きにするため）。
