# TOMORI READY 使い方ガイド

あしたの じゅんび、できたかな？

## はじめに

TOMORI READYは、学校へ持っていくものを**前の晩**に確認するアプリです。ひらくと、すぐに今日・あしたの持ち物が出ます。

## 基本の使い方

1. **「じゅんび」画面を開く。** 夜はじめから「あした」が選ばれています（お昼まではじめから「きょう」）。「きょう」「あした」は上のボタンで切りかえます。
2. **持ち物をカバンに入れながら、大きなチェックボタンをタップ。** ✓がついて、「OK!」と出ます。まちがえたら、もう一度タップするとはずれます。
3. **上の数と％を見る。** 「5 / 8 こ じゅんびOK」「63%」のように、あといくつかがわかります。
4. **ぜんぶチェックできたらお祝い！** 紙ふぶきの画面が出ます。「やったー！」でとじます。

> チェックは日付ごとに別々です。きのうのチェックが、あしたに残ることはありません。

## 持ち物を変えたいとき（「せってい」画面）

学校によって持ち物はちがうので、すべて自由に変えられます。

1. 下の「せってい」をタップ。
2. **① 曜日をえらぶ**：月〜日のどれかをタップ。
3. **② その曜日に もっていくもの**：「あり／なし」をタップして、その曜日に持っていくかどうかを決めます。
   - ✏️ で名前や絵文字をなおせます。
   - 🗑️ でけせます（ぜんぶの曜日からきえます。「けす」をおすまでは消えません）。
4. **③ もちものを ふやす**：「習字セット」「絵の具セット」「体操服」「上ばき」「図書の本」はワンタップで追加。じぶんで名前を入れて、絵文字をえらんで「ふやす」もできます。ふやしたものは、えらんでいる曜日に入ります。ほかの曜日にも持っていくなら、②で「あり」にします。

はじめから入っている「ランドセル」「ふでばこ」「教科書」「ノート」「ハンカチ」「ティッシュ」「水とう」「連絡帳」は月〜金に入っています。土・日は空っぽです（持ち物のない日は、そう表示されます）。

## 保護者の方へ

- 入力した内容と、チェックの状況は、**この端末のブラウザの中だけ**に保存されます。サーバーには送信されません。会員登録・広告・課金・通知はありません。
- **ブラウザの「サイトデータ」「閲覧履歴」を削除すると、設定もチェックも消えて、初期の状態に戻ります。** 別の端末・別のブラウザには引き継がれません。プライベートブラウズでは、閉じると消えることがあります。
- 名前・学校名・住所・連絡先などは、入力しないようにしてください。持ち物の名前にも入れないでください。
- 持ち物の初期サンプルは見本です。学校からのお知らせに合わせて、お子さんと一緒に設定してください。
- iPhoneでは Safari の「共有 → ホーム画面に追加」で、アプリのように開けます。

## こまったとき

| こと | こたえ |
| --- | --- |
| 持ち物が出てこない | 「きょう」「あした」が土・日だと空っぽです。「せってい」でその曜日に「あり」にしてください。 |
| 設定が消えた | ブラウザのデータを削除した可能性があります。もう一度設定してください。 |
| 日付がへん | 端末の日付・時刻の設定を確認してください。アプリは端末の日付を使います。 |
